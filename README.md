# Change Audiobook

A project developed during an intensive **JavaScript** course.  
The goal was to create an audiobook player that allows users to:
- Change the chapter currently playing
- Play or pause the current chapter

### Features
- Chapter navigation
- Play/Pause functionality for audiobooks
